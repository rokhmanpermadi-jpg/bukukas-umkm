# Buku Kas UMKM — APK Android

Aplikasi pembukuan usaha sederhana (offline) gratis untuk usaha mikro dan kecil: tanpa akun, tanpa iklan, tanpa internet.
Aplikasi web berada di `app/src/main/assets/www/`; proyek Android membungkusnya dalam WebView dan menambahkan simpan/bagikan berkas.

APK dibangun otomatis oleh GitHub Actions pada setiap push ke `main`: lihat tab **Releases** untuk mengunduh `BukuKasUMKM.apk`.
